# /assets/images/testimony/

Images for the traveller testimonials. The text lives in `assets/js/testimony.js`
(one entry per traveller); each entry points at files in this folder.

| Used for | Path | Files expected |
|---|---|---|
| Trip photo / avatar (home + about) | `assets/images/testimony/` | `leh.jpg`, `goa-beach.jpg`, `rajasthan.jpg`, `kedarkanth.jpg`, `goa-north.jpg`, `western-ghats.jpg`, `ooty.jpg`, `vietnam.jpg` |
| Flip-card background (about page) | `assets/images/testimony/bg/` | `testimony-1.png` ... `testimony-8.png` |

To add a story: drop its image here, then add one line to `testimony.js`.
Keep each image under 1 MB. A missing image falls back to a plain tone block.
